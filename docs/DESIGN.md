# Design System — Quiet Instrument

## 产品气质

三个词：**克制、可信、持续运行**。

这是一个需要长时间盯着看的专业工作台，不是营销落地页。视觉重点不是“展示智能感”，而是让用户快速判断：当前在做什么、为什么这么做、证据够不够、自己是否仍掌握控制权。

## 设计 DNA

### 1. 工作台优先，不用巨型 Hero 抢走操作空间

欢迎页只承担“告诉用户怎么开始”的任务。主标题控制在桌面 31–42px、移动端 29–31px；进入真实任务后，界面回到 10–17px 的稳定操作层级。任何标题都不能比任务本身更有存在感。

### 2. 一个主色 + 一个温暖风险色

主色是低饱和矿物蓝绿 `#355E68`，负责当前选择、主要动作、执行状态和可信链接。暖棕 `#A96443` 只表示停止、风险、外部或需要注意的状态。

不再使用酸性荧光黄绿，也不让两个高饱和色同时竞争注意力。

### 3. 中性背景必须带一点冷暖关系

- Canvas `#F2F3F1`
- Main surface `#FBFBF8`
- Secondary surface `#ECEFEB`
- Structural surface `#E3E7E3`

这些颜色足够接近，形成产品级连续空间，但通过明度差区分主工作区、导航和证据轨道。禁止大面积纯黑、纯白和无色温的灰。

### 4. 无衬线承担全部中文主层级

上一套大号中文衬线标题在这个产品里过于“刊物化”，与持续操作的工作台不一致。现在 display 与 UI 都使用本机无衬线栈，通过字号、字重和字距建立层级，而不是通过字体类别制造戏剧性。

本地优先，不请求远程字体：

- UI / Display: `Avenir Next / SF Pro / Segoe UI / PingFang SC / Hiragino Sans GB / Microsoft YaHei / Noto Sans CJK SC`
- Mono labels: `SFMono-Regular / Cascadia Code / Roboto Mono / Consolas`

客户正文最小 10px；主要正文 12–14px；操作标题 13–17px；欢迎页标题最高 42px。

### 5. 扁平结构，只有真正需要承载交互的地方浮起

左侧模式、Inspector、证据列表继续依靠分隔线、留白和背景层级组织，不做卡片墙。

只有以下元素可以使用明显圆角/阴影：

- Composer
- 用户输入气泡
- 运行状态块
- 附件
- 小型按钮/状态 chip

这样圆角是功能语义，不是默认组件皮肤。

## 页面结构

### Desktop

1. Top status rail — 品牌、数据与能力状态
2. Left mode rail — 搜索 / 推荐 / 自主优化 / 全局体检 + 历史
3. Main stage — 目标、任务输出、运行状态、composer
4. Evidence rail — 执行轨迹 / 判断依据 / 工作区

### Tablet

模式区压缩成横向任务条；证据区变为右侧抽屉。不同任务仍可并行，不因为一个长任务锁死整个工作台。

### Mobile

主工作区单列；证据通过“查看证据”打开。移动端不能删除证据能力，也不能把关键操作缩成难以触达的小图标。

## Composer

Composer 是页面唯一应该有明显“工具感”的悬浮表面。

支持：

- 自然语言目标；
- 拖入文件；
- 粘贴截图；
- 图片缩略图；
- JSON / CSV / Markdown / TXT；
- 单次联网权限；
- 运行中停止。

附件与联网状态必须在发送前可见，发送后继续留在用户消息上下文中。

## Motion language

所有动效统一使用 `cubic-bezier(.2,.72,.24,1)`，默认 150–260ms；持续状态脉冲可以更慢，但不能弹跳。

动效只承担五类职责：

1. **进入层级**：首次加载时 hero、能力说明、常用起点依次淡入；
2. **状态推进**：运行状态与进度条平滑更新；
3. **上下文出现**：消息、附件、timeline row 轻量进入；
4. **空间切换**：Inspector 抽屉与 panel 切换；
5. **操作反馈**：hover、focus、pressed 只做 1–2px 光学位移或颜色变化。

`prefers-reduced-motion` 必须关闭连续动画和长过渡，同时保留最终状态。

## 控制权

高级自主产品必须让用户随时知道“系统正在做什么”和“我能不能停”。

因此运行态必须提供停止入口。停止请求不会粗暴打断当前同步动作，而是在当前动作结束后阻止新的工具扩展，并将 run 进入明确的 cancelled 状态。

## 客户文案边界

客户 UI 允许：搜索体验、推荐体验、自主优化、全局体检、执行轨迹、判断依据、工作区、图片感知、联网研究、公开来源、稳定验证。

客户 UI 不出现内部模型名、第三方产品名，也不出现 BM25、embedding / 向量、召回 / 重排、MMR、NDCG / MRR、policy model 等内部术语。

## Anti-slop checklist

每次 UI 变更至少检查：

- 无远程字体依赖；
- 无紫蓝 AI 渐变；
- 无玻璃拟态；
- 无荧光高饱和色争夺主注意力；
- 无卡片套卡片；
- 无圆角方块图标墙；
- 客户字体不低于 10px；
- 产品级大标题不超过 42px；
- 关键触控目标至少 40px，移动端优先 44px；
- 证据能力在移动端仍存在；
- 运行中可以停止；
- 键盘 focus 清晰；
- 中文 IME 不误触发送；
- drag/drop 与 paste 不阻断普通文本输入；
- reduced motion 有明确降级；
- 页面不包含其他产品或模型品牌名。
