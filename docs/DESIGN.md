# Design System — Editorial Control Room

## 模式

Operate：用户来这里是为了完成任务，不是看营销页面。

## 设计北极星

**编辑台 / 运营控制室**。

不是紫色 AI SaaS，不做玻璃拟态，不把所有内容包成圆角卡片。品牌感来自版式、字体、单一高亮色和信息节奏。

## 色彩

- Warm paper: `#F2F0E9`
- Surface: `#FBFAF5`
- Ink: `#16231B`
- Muted: `#69736C`
- Line: `#D7DBD2`
- Accent: `#C8F06A`
- Accent deep: `#315B2E`

酸性黄绿只用于：当前选择、确认完成、关键强调。不要把它铺满页面。

## 字体

- Display: Noto Serif SC
- UI / body: Manrope + 中文系统字体回退

大标题用衬线制造“编辑台”气质；操作区保持高扫描效率。

## 空间

- 主对话是视觉中心；
- 左侧只做任务导航与历史；
- 右侧只做执行证据；
- 大部分分组靠 1px 分隔线，不靠卡片背景；
- 圆角只保留在头像等自然需要圆形的地方。

## 动效

- 150–220ms；
- 只表达状态变化；
- 执行中使用缩放闪烁方块与进度线；
- hover 主要使用 6–9px 的轻微内容位移；
- `prefers-reduced-motion` 全面关闭动画。

## 客户文案约束

禁止出现在客户 UI 的词：

- BM25
- embedding / 向量
- 召回
- 重排
- MMR
- 图模型
- NDCG / MRR
- policy model

允许：

- 搜索体验
- 推荐体验
- 结果是否准确
- 内容覆盖
- 新鲜度
- 方案复核
- 小流量验证
- 判断依据

## 自查清单

- 无紫蓝渐变；
- 无玻璃拟态；
- 无卡片套卡片；
- 无圆角方块图标墙；
- 不用颜色单独表达状态；
- 键盘 focus 可见；
- 移动端主任务仍可完成；
- 动效支持 reduced motion。
